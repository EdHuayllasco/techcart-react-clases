# TechCart — Bloque React (guiones del docente)

Repositorio del **bloque de React** del bootcamp FrontEnd. React tiene numeración propia:
**12 clases** (clase 1 a 12 de React), que continúan el curso de fundamentos (HTML, CSS,
JavaScript y TypeScript, 12 clases en su propio repositorio).

Cada carpeta `clase-XX/` contiene el `GUION-DOCENTE.md` de esa sesión y, cuando existan, sus
diapositivas y material de apoyo. Las reglas de diseño de clase (modelo de tiempo, reglas de la
modalidad virtual, estilo de los materiales) viven en el
`MAPA-CAPACIDAD-4h15.md` de `techcart-clases`.

> Cada clase dura **4:15 de contenido** (el receso de 15 min va aparte). Se dicta en
> **TypeScript** desde la clase 1. El proyecto es una **tienda nueva, desde cero absoluto**,
> con la estética de las tiendas grandes (plantilla de referencia estilo iStore); cada alumno
> bautiza la suya. Rige el **modelo de flujo**: cada guion carga material de sobra, la clase se
> corta donde toque a las 3:50, y la siguiente retoma exacto — los temas por clase son cortes
> sugeridos.

## Ruta del bloque (12 clases)

| Clase | Tema | Se agrega a la tienda |
|:--:|---|---|
| 01 | Introducción a React + Vite (plantilla React + TS) + JSX | Proyecto desde cero: contrato + catálogo semilla |
| 02 | Componentes funcionales + props tipadas | Las cards como componentes |
| 03 | Renderizado condicional + renderizado de listas | Catálogo con estados y `key` |
| 04 | Manejo de eventos + `useState` | Carrito con estado |
| 05 | `useState` II: estado derivado + buscador | Filtro por categoría + buscador |
| 06 | `useEffect` + ciclo de vida (cleanup, StrictMode) | Persistencia del carrito |
| 07 | Consumo de API REST + estados de carga + errores | Los 38 productos con skeleton y reintento |
| 08 | React Router | Navegación: catálogo, detalle, carrito, 404 |
| 09 | Formularios controlados + validación por campo | Checkout controlado |
| 10 | Custom hooks + Context API + estado global | `useFetch`, `useCart`, carrito global |
| 11 | JWT + persistencia de sesión + rutas protegidas + variables de entorno | Login real y protección |
| 12 | Optimización (`memo`, `useMemo`, `lazy`) + despliegue en Vercel | Producción + arranque del proyecto final |

El proyecto final se presenta en semanas aparte, después de la clase 12.
