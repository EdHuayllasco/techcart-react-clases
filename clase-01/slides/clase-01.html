Qué es React, en serio

Una sola idea

UI = f(datos)

Tú cambias el dato — React repinta. Se acabó el acordarse.

imperativo — fundamentos
das órdenes: busca el elemento, bórralo, inserta el HTML. Como un for que acumula.
declarativo — React
describes el resultado: "la pantalla es esto, dados estos datos". Como un reduce.

TecsupMASTERCLASS
02
Tres aclaraciones antes de escribir una línea

Qué NO es React

No es un framework
Un framework decide todo por ti — como Spring en Java. React es una biblioteca: una pieza que hace una sola cosa.
No es un lenguaje
Sigue siendo TypeScript. Lo único nuevo de hoy es que una función pueda devolver HTML.
No reemplaza lo aprendido
HTML, CSS, fetch, map, filter: todo se usa tal cual, dentro de React.

El código se escribe nuevo; el conocimiento es el mismo.

JSX
TecsupMASTERCLASS
04
La única pieza genuinamente nueva de hoy

JSX: la función que devuelve HTML

lo que escribes — App.tsx
export default function App() {
  return <h1>Tienda Tec</h1>;
}
→
lo que el navegador recibe (traducido)
export default function App() {
  return createElement('h1', null, 'Tienda Tec');
}

Igual que TypeScript: escribes cómodo, un traductor convierte, el navegador recibe JavaScript de siempre.
.tsx = TypeScript + JSX.
